Setup Help

  1. Create a free project at supabase.com.
  2. In the SQL Editor, run:
    create table sessions ( id text primary key, date text not null, start_time timestamptz not null, end_time timestamptz not null, seconds integer not null, updated_at timestamptz default now() );
  3. Disable Row Level Security for the sessions table, or add an open policy.
  4. Copy the Project URL and anon key from Project Settings, paste them above and tap Connect & Sync.
  5. Repeat step 4 on every device or browser. Everything stays in sync.
