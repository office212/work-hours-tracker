Setup Help

  1. Create a project in the Google Cloud Console and enable the Google Sheets API.
  2. Create an OAuth 2.0 Client ID (Web application) and add this site as an authorized JavaScript origin.
  3. Paste the Client ID above and tap Connect Google.
  4. On first connect a new spreadsheet is created automatically, unless you pasted an existing Spreadsheet ID.
